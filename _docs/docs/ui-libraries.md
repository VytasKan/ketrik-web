# Supported UI & Visualization Libraries

An overview of the external open-source UI libraries, charting engines, rich-text formatters, and interactive components supported and integrated across the platform.

---

## 1. Charting & Data Visualization

| Library / Engine | Core Dependencies | Supported Visualizations & Capabilities |
| :--- | :--- | :--- |
| **Recharts** | `recharts` (^3.10.1) | Declarative React charts: Area, Bar, Line, Pie, Composed charts, and Responsive Containers |
| **Chart.js** | `chart.js` (^4.5.1)<br>`react-chartjs-2` (^5.3.1) | Line, Bar, Pie, Doughnut, Radar, Polar Area, Boxplot, Funnel, Graph/Network diagrams, Parallel Coordinates, Sankey, Word Clouds, and DataLabels plugins |
| **ApexCharts** | `apexcharts` (^6.8.0)<br>`react-apexcharts` (^2.1.1) | Interactive Line, Area, Bar, Mixed/Combo charts, Heatmaps, Radial Gauges, Candlestick, and Scatter plots |
| **MUI X Charts** | `@mui/x-charts` (^9.11.1) | Material UI native charts: Bar, Line, Scatter, Pie, Sparkline, Gauge, and theme-synchronized styling |
| **Lightweight Charts** | `lightweight-charts` (^5.2.1) | High-performance financial & trading charts (TradingView): Candlestick, Area, Line, Baseline, Yield Curves |
| **Plotly.js** | `plotly.js-dist-min` (^3.7.0) | Scientific & statistical plots: 2D/3D Surface, Contour, Heatmap, Choropleth maps, Financial time-series, Violin & Box plots |
| **Google Charts** | `react-google-charts` (^5.2.1) | GeoCharts, OrgCharts, Timelines, Sankey diagrams, Treemaps, and Word Trees |
| **D3.js** | `d3` (^7.9.0) | Low-level customized SVG and HTML Canvas data visualizations |

## 2. Content, Text & Rich Media

| Component / Utility | Core Dependencies | Features & Capabilities |
| :--- | :--- | :--- |
| **Markdown Renderer** | `react-markdown` (^10.1.0)<br>`remark-gfm`<br>`remark-math`<br>`rehype-katex` | GitHub-flavored Markdown (GFM), LaTeX math notation via KaTeX, code blocks, and formatted tables |
| **Streaming Markdown** | `streamdown` (^2.5.0) | Real-time streaming markdown rendering optimized for AI/LLM chat completions |
| **Monaco Code Editor** | `monaco-editor` (^0.56.0)<br>`@monaco-editor/react` (^4.7.0) | In-browser VS Code editing experience with multi-language syntax highlighting, themes, and code editing |
| **Interactive Flow / Graph** | `reactflow` (^11.11.4)<br>`dagre` (^0.8.5) | Node-based workflows, flowcharts, DAG diagrams, and draggable interactive canvas |
| **Dynamic JSON Schema Forms** | `@rjsf/core` (^6.8.0)<br>`@rjsf/mui` (^6.8.0)<br>`@rjsf/validator-ajv8` (^6.8.0) | Schema-driven form generation via JSON Schema with Material UI widget bindings and AJV validation |
| **Syntax Highlighting** | `react-syntax-highlighter` (^16.1.1) | Multi-theme code and JSON syntax viewer with tabbed and tokenized inspection |

| Layer / Toolkit | Core Dependencies | Description |
| :--- | :--- | :--- |
